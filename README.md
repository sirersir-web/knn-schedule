# PDF Schedule Parser (Парсер расписания занятий из PDF)

Скрипт на Python с использованием библиотеки `pdfplumber` для извлечения расписания занятий колледжей и вузов из PDF-файлов в структурированный формат JSON.

## Спецификация структуры JSON

Скрипт формирует JSON строго в заданном формате:

```json
{
  "group": "3421",
  "date": "2026-10-30",
  "week": 1,
  "parsed at": "2026-10-30T19:04:50+03:00",
  "lessons": [
    {
      "num": 1,
      "time": "08:30 - 10:00",
      "subject": "Разработка программных модулей",
      "teacher": "Смирнов А.В.",
      "room": "каб. 402"
    }
  ]
}
```

### Описание полей:
- `group`: Номер / шифр учебной группы (например, `"3421"`). Определяется автоматически из документа либо задается аргументом `--group`.
- `date`: Дата расписания в формате `YYYY-MM-DD` (автоматически определяется из текста шапки: `30.10.2026`, `30 октября 2026` и др., либо текущая дата).
- `week`: Номер недели (`int`, например `1` или `2`). Автоматически определяется из шапки (`I неделя`, `II неделя`, `1 неделя` и др.), либо задается аргументом `-w / --week`.
- `parsed at`: ISO 8601 таймштамп момента выполнения парсинга.
- `lessons`: Список занятий (пар/уроков), каждый элемент содержит:
  - `num`: Порядковый номер пары (число `int`).
  - `time`: Время проведения занятия (строка, например `"08:30 - 10:00"`).
  - `subject`: Наименование дисциплины / предмета.
  - `teacher`: ФИО преподавателя (например, `"Смирнов А.В."`).
  - `room`: Кабинет / аудитория (например, `"каб. 402"`, `"305"`, `"спортзал"`, `"дистант"`).

---

## Поддерживаемые форматы расписания

1. **Колоночный формат с группами** (*самый частый в колледжах*):
   - Столбцы таблицы представляют учебные группы (`3421`, `3422`, ...).
   - В ячейках содержится предмет, преподаватель и аудитория (в 2–3 строки или через разделители).
   - Поддерживаются подгруппы (`1 п/г`, `2 п/г`).
2. **Строчный формат** (отдельная таблица на группу):
   - Столбцы: `№`, `Время`, `Дисциплина`, `Преподаватель`, `Аудитория`.
3. **Текстовый формат** (без явных линий таблиц):
   - Резервный парсер строк текста с временными метками пар.

## Использование через консоль (CLI)

### 1. Парсинг одного файла:
```bash
# Базовый запуск (вывод в консоль)
python3 parse_schedule.py schedule.pdf

# С указанием конкретной группы и сохранением в файл
python3 parse_schedule.py schedule.pdf --group 3421 -o output.json
```

### 2. Парсинг множества файлов (мульти-парсинг):
Скрипт поддерживает передачу нескольких файлов, масок (wildcard) и целых папок:

```bash
# Передать список файлов
python3 parse_schedule.py file1.pdf file2.pdf file3.pdf -g 3421 -o all_days.json

# Использовать маску *.pdf
python3 parse_schedule.py *.pdf -g 3421 -o week_3421.json

# Указать папку (сканирует все .pdf файлы внутри)
python3 parse_schedule.py ./schedules/ -g 3421 -o full_schedule.json

# Сохранить каждый распарсенный PDF в отдельный JSON-файл в папку
python3 parse_schedule.py ./schedules/ -g 3421 --out-dir ./parsed_json/
```

### 3. Экспорт всех групп из файла:
```bash
python3 parse_schedule.py schedule.pdf --all-groups -o all_groups.json
```

### Параметры командной строки:
| Флаг | Описание |
|---|---|
| `pdf_inputs` | Один или несколько файлов PDF, маска (например `*.pdf`), или путь к папке |
| `-g`, `--group` | Номер/шифр группы (например `3421`) |
| `-d`, `--date` | Переопределить дату (например `2026-10-31`) |
| `-w`, `--week` | Переопределить номер недели (например `1` или `2`) |
| `-o`, `--output` | Путь к файлу для сохранения объединенного JSON |
| `--out-dir` | Папка для сохранения отдельных JSON-файлов для каждого PDF |
| `--indent` | Количество пробелов отступа JSON (по умолчанию `2`) |
| `--all-groups` | Извлечь данные по всем найденным группам |
| `--include-empty` | Включать пустые пары / окна в список занятий |
| `--retention-days N` | Сохранять расписание за последние N дней и будущие даты, более старые удалять |
| `--clean-files` | Автоматически удалять с диска старые PDF-файлы (старше retention-days) |
| `--deduplicate` | Дедуплицировать: новое расписание на тот же день заменяет старое |
| `--as-list` | Всегда выводить JSON-массив `[...]`, даже для одного дня |

## Использование в Python коде

### Обработка одного файла:
```python
from parse_schedule import parse_schedule_pdf

data = parse_schedule_pdf("schedule.pdf", group="3421")
print(f"Группа: {data['group']}, Дата: {data['date']}, Занятий найдено: {len(data['lessons'])}")

for lesson in data["lessons"]:
    print(f"{lesson['num']}. [{lesson['time']}] {lesson['subject']} | {lesson['teacher']} | {lesson['room']}")
```

### Обработка множества файлов или папки:
```python
from parse_schedule import collect_pdf_files, parse_multiple_pdfs

# 1. Найти все PDF файлы в папке или по маске
pdf_files = collect_pdf_files(["./schedules/"])

# 2. Распарсить все файлы для группы 3421
all_schedules = parse_multiple_pdfs(pdf_files, group="3421")

# Результаты автоматически отсортированы по дате
for day in all_schedules:
    print(f"=== {day['date']} ===")
    for lesson in day["lessons"]:
        print(f"  #{lesson['num']} [{lesson['time']}] {lesson['subject']} | {lesson['teacher']} | {lesson['room']}")
```

## Автоматическая загрузка расписания из ВК (`vk_downloader.py`)

Модуль `vk_downloader.py` позволяет автоматически скачивать свежие PDF-файлы расписания со стены сообщества ВКонтакте, избегая повторных загрузок с помощью файла состояния `.last_vk_doc.json`.

### Параметры конфигурации:
Поддерживаются как переменные окружения, так и флаги CLI:

| Переменная окружения | Флаг CLI | Описание | По умолчанию |
|---|---|---|---|
| `VK_SERVICE_TOKEN` | `-t`, `--token` | Сервисный ключ доступа VK API | *Обязательно* |
| `VK_GROUP_ID` | `-g`, `--group-id` | ID сообщества (числовой, например `12345` или `club12345`) | - |
| `VK_DOMAIN` | `-d`, `--domain` | Короткое имя / домен сообщества (например `my_college`) | - |
| `TARGET_KEYWORDS` | `-k`, `--keywords` | Ключевые слова для фильтрации названий файлов (через запятую) | - |
| `TARGET_REGEX` | `-r`, `--regex` | Регулярное выражение для фильтрации названий файлов | - |
| `OUTPUT_DIR` | `-o`, `--output-dir` | Папка для сохранения скачанных PDF | `./downloads` |
| `STATE_FILE` | `-s`, `--state-file` | Путь к файлу состояния обработанных документов | `.last_vk_doc.json` |
| `VK_COUNT` | `-c`, `--count` | Количество проверяемых постов на стене | `20` |
| - | `-f`, `--force` | Принудительная повторная загрузка (игнорировать state) | `False` |
| - | `-q`, `--quiet` | Тихий режим (только путь к файлу в stdout) | `False` |

### Примеры использования CLI:

```bash
# С использованием флагов:
python3 vk_downloader.py \
  --token "vk1.a..." \
  --group-id "123456" \
  --keywords "расписание" "3-4 курс" \
  --output-dir "./downloads"

# С использованием переменных окружения:
export VK_SERVICE_TOKEN="vk1.a..."
export VK_GROUP_ID="123456"
export TARGET_KEYWORDS="расписание, 3-4 курс"
python3 vk_downloader.py

# Связка загрузки и последующего парсинга в одной команде:
python3 parse_schedule.py $(python3 vk_downloader.py) --group 3421 -o output.json
```

### Использование в Python коде:

```python
from vk_downloader import fetch_schedule
from parse_schedule import parse_schedule_pdf

# Скачивание актуального PDF (или получение пути к уже загруженному)
pdf_path = fetch_schedule(
    token="vk1.a...",
    group_id="123456",
    keywords=["расписание", "3-4 курс"],
    output_dir="./downloads"
)

# Парсинг расписания для конкретной группы
schedule_data = parse_schedule_pdf(pdf_path, group="3421")
print(f"Дата: {schedule_data['date']}, Занятий: {len(schedule_data['lessons'])}")
```
